TemPad documentation ​

TemPad is a personal task calendar with automated scheduling and task dependencies, inspired by FlowSavvy Pro and the TVA timeline devices in Marvel's Loki.

Quick links ​

  • Open TemPad — use the live app
  • Getting started tutorial — five-minute walkthrough for new users

App preview ​

What you can do ​

  • Auto-schedule tasks into your available hours (up to 8 weeks ahead)
  • Triage with List, Kanban, Eisenhower, and optional Gantt (beta) task layouts
  • Chain tasks with dependencies and priority levels
  • Import Google Calendar events as busy blocks and sync edits back
  • Drag tasks on the week calendar; lock manual placements until you reschedule
  • Customize list colors, themes, schedule breaks, and multiple scheduling-hour profiles
