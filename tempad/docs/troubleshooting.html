Troubleshooting ​

Google Calendar 401 / 403 or missing calendars ​

  1. Enable the Google Calendar API on your Google Cloud project linked to Firebase.
  2. In TemPad: Settings → Google Calendar sync → Connect calendars and approve all requested permissions.
  3. If you previously connected before the API was enabled, disconnect/reconnect to refresh the token.

No writable calendar for export ​

  • Pick a Google calendar you own or can edit
  • Reconnect calendars and confirm write permission in the Google consent screen

Sync not running ​

  • You must be signed in (not local-only)
  • Enable at least one calendar in Settings
  • Keep the tab open or return to it — use Sync now to force a pull

Changes not on other devices ​

  • Confirm Google sign-in (cloud sync), not Continue without sign-in
  • Check Firestore rules are deployed from firestore.rules
  • Verify Firebase env vars match your project (see README)

Tasks not scheduling ​

  • Task needs due date and duration
  • List’s scheduling hours profile must have enabled days with valid start/end
  • Press Reschedule after bulk edits
  • Locked (dragged) blocks stay put until reschedule unlocks them

Sign-in on GitHub Pages ​

  • Add YOUR_USERNAME.github.io to Firebase authorized domains
  • Popup may be replaced by redirect on github.io — wait for redirect to complete

Local development ​

  • Use .env.local from .env.example for Firebase
  • Without Firebase: Continue without sign-in only

Still stuck? ​

Open an issue on GitHub with browser console errors and whether you use local or signed-in mode.
