On this page

Settings ​

Open Settings from the sidebar. On desktop, section links also appear in the top toolbar when you are on Settings.

Appearance ​

Settings → Theme (or Appearance):

  • Modern Dark / Light — neutral purple UI
  • Phosphor / Variance — TVA terminal palettes (green or orange on black)
  • Dossier — parchment and rust accents (warm light)
  • Frost — cool slate and teal (calm light, not warm or product-blue)
  • Vibe Dark / Light — monday.com-style product UI

Optional: scheduled light/dark switching by time of day.

Lists ​

  • Default list for new tasks
  • List colors — presets, custom hex, Random color
  • Keep list colors across themes — same hex everywhere, or slight light/dark adjustment at render time

Colors appear on calendar chips, task rows, filters, and list indicators.

Scheduling hours ​

Profiles define when tasks can be placed (e.g. Work hours 9–5 weekdays, Personal evenings). Each list links to one profile.

Expand Manage scheduling hours to edit day-by-day enable/start/end. Copy first day to all days when setting up a new profile.

Scheduler ​

  • Scheduling horizon — how many weeks ahead to plan (default 8)
  • Schedule breaks — optional gaps after X minutes of work and/or X tasks (empty space in the plan, not separate “Break” events)
  • Auto-reschedule after edits — when off, task/routine/settings edits save but the calendar does not move until you press Reschedule on the Calendar view
  • Auto-reschedule routines — when off, routine blocks stay put when you edit routines or run Reschedule; tasks still move (default on)
  • Reschedule delay (tasks) — wait time after task edits before the scheduler runs (0 = immediately). Changing delay or turning auto-reschedule on/off does not reshuffle the plan by itself
  • Reschedule delay (routines) — optional longer debounce for routine edits (e.g. tuning several meal windows); Same as tasks uses the task delay
  • Splittable defaults and related toggles
  • Subtasks (advanced) — enable parent tasks with ordered sub-steps, calendar sub-segments, and nested list rows (default off; toggling does not reshuffle the calendar)
  • Subroutines (advanced) — nest routines under other routines in the Routines view; each routine still schedules on its own (default off)
  • Gantt view (beta) — adds a Gantt layout tab on the Tasks view; shows auto-scheduled tasks as timeline bars (default off; toggling does not reshuffle the calendar)

Tasks and Eisenhower ​

Under Tasks (or Theme / task-related toggles):

  • Use task priorities — enables ASAP / High / Normal / Low; ASAP tasks land in the Do first quadrant
  • Show inbox tasks in Eisenhower matrix — include inbox/backlog items when using Matrix layout on the Tasks view
  • Drop task onto task — in List, Kanban, and Matrix, dropping one task on another creates a subtask (default) or creates a dependency; pair with Subtasks (advanced) for subtask mode
  • Dependency drag direction — which task depends on the other when drop mode is Create dependency

See Tasks for quadrant meanings and drag-to-triage behavior.

See Tasks — Gantt mode (beta) for what appears on the timeline and how it relates to Reschedule.

Calendar display ​

Week/day/month default, show event end times, skipped tasks on calendar, etc.
