On this page

Calendar ​

The Calendar view is your planning surface: week, day, or month layout with drag-and-drop scheduling.

Views ​

Switch view mode from the calendar toolbar or Settings:

  • Week — primary scheduling view; tasks appear as blocks in time slots
  • Day — focus on a single day
  • Month — overview; useful for spotting density and navigating dates

Reschedule ​

Press Recalculate schedule (toolbar refresh icon) to:

  1. Unlock all manually dragged (locked) task blocks
  2. Re-run the auto-scheduler for incomplete auto-scheduled tasks

Run reschedule after you change tasks, events, scheduling hours, or import data. The engine does not continuously reshuffle in the background.

How blocks are placed ​

  1. Tasks are ordered by priority, then due date
  2. Dependencies are respected (a task cannot start before its predecessors finish)
  3. Free slots are found inside the task’s scheduling hours profile, avoiding busy events and other scheduled items
  4. Splittable tasks can use multiple smaller blocks; non-splittable tasks need one contiguous slot

Drag and lock ​

  • Click a block to edit it
  • Drag to move a task or event to a new time
  • Dragged task blocks become locked (dashed outline) until the next Reschedule
  • Overlapping blocks in the same hour are shown side-by-side

Google Calendar busy blocks ​

Imported Google events appear as busy constraints. TemPad auto-syncs while the tab is open (and when you return). Use Sync now in Settings for an immediate pull.

See Google Calendar for connect and two-way sync details.
