Google Calendar sync ​

Connect Google Calendar so meetings and events block auto-scheduling, and optionally push TemPad changes back to Google.

Prerequisites ​

  1. Sign in with Google (Firebase) — not local-only mode
  2. Enable the Google Calendar API on your Firebase/Google Cloud project
  3. Add your site domain under Firebase Authentication → Authorized domains (e.g. localhost, jaredescott.github.io)

Connect ​

  1. Open Settings → Google Calendar sync
  2. Click Connect calendars and approve calendar access
  3. Enable each calendar you want as busy blocks (work, personal, shared, etc.)
  4. Use Sync now for an immediate pull; otherwise TemPad syncs periodically while the tab is open and when you return to the tab

Synced events cover the next 8 weeks (plus range when you navigate outside that horizon). Google event colors appear on the week view.

What syncs both ways ​

  • Import: Google events → TemPad busy blocks
  • Edits: Changes to imported events in TemPad push back when permissions allow
  • Local events: Can be pushed to a writable Google calendar
  • Conflicts: Google wins on merge

Export scheduled tasks (optional) ​

Enable task export and choose a writable target calendar:

  • Block-based — scheduled task blocks become Google events
  • Manual-only — export when you explicitly trigger it

If no writable calendars appear, reconnect and re-approve access.

Scopes and 403 errors ​

TemPad requests calendar scopes needed for listing calendars and reading/writing events. A 403 on calendarList usually means:

  • Calendar API is disabled in Google Cloud, or
  • The access token lacks scope — use Connect calendars again after fixing the API

On github.io, sign-in uses redirect instead of popup to avoid Cross-Origin-Opener-Policy issues.

Tokens ​

Google access tokens are cached in session storage. If sync stops working, reconnect calendars from Settings.
