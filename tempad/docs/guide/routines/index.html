Routines ​

Routines are recurring protected-time patterns — separate from one-off tasks and fixed events.

Routines vs tasks vs events ​

KindUse for
TasksActionable work with due dates, duration, priorities, dependencies, splittable scheduling
EventsTime blocks that reserve calendar time and act as busy constraints for the scheduler
RoutinesRepeated structures: morning planning, workouts, deep-work windows, weekly reviews

When to use routines ​

Use routines when the time pattern repeats (daily, weekly, monthly style cadence) and you want protected structure on the timeline without treating each occurrence as a separate task to complete.

Use tasks when you need due dates, completion, and splitting around meetings.

Dependencies ​

Routines can participate in the same dependency links as tasks. In the routine editor, use Depends on to wait until other tasks or routines finish, and Blocks to list items that must wait for this routine.

  • The scheduler orders routines and tasks together; cycles are rejected.
  • A routine that depends on another item: each scheduled occurrence starts only after that prerequisite’s end time for the current reschedule pass.
  • A task that depends on a repeating routine waits until the first scheduled occurrence in the horizon finishes (same rule as other repeating prerequisites). For “after today’s lunch, do X,” set the task to depend on the Lunch routine.

See Tasks — Dependencies for drop-to-link behavior in list views (tasks only; link routines in the editor).

Creating routines ​

Open Routines from the sidebar, pick a preset, or use New to open the editor. Set title, duration, repeat cadence, and when the routine should land on your calendar.

Subroutines (advanced) ​

Off by default. Turn on Subroutines (advanced) in Settings → Scheduler to nest routines under a parent in the Routines view. Drag to reorder or reparent. Each routine still schedules independently; nesting is for organization only.

Smart editor layout ​

Routine editing uses the same Smart task editor behavior as tasks (see Tasks — Smart editor layout): preset, duration, time window, scheduling profile, and repeats stay easy to reach; less-used fields (flexible duration, notes, list) may move under More options based on your saved routines. Override in Settings → Scheduler.

Time window (clock) ​

The routine editor uses a clock dial instead of separate time fields:

  • Drag the arc ends to set the allowed window start and window end (overnight windows, e.g. sleep, wrap past midnight on the dial).
  • Drag the inner dot for preferred start — where TemPad tries to place the block inside the window.
  • A summary line under the dial shows the exact times (e.g. 11:30 AM – 1:30 PM · prefers 12:15 PM).
  • Scheduling profile chooses which weekdays apply (chips under the dial mirror enabled days). Change profile day boundaries in Settings → Scheduling hours.

Reschedule delay (routines) ​

In Settings → Scheduler, Reschedule delay (routines) can be longer than the task delay (or Same as tasks). Routine saves debounce separately but still trigger a single scheduler pass when the timer fires. Use Reschedule on the Calendar for an immediate run (including meal spacing).

Meal spacing ​

On the next Reschedule pass (auto or manual), TemPad spreads multiple meal routines across the same day if their titles match: breakfast, lunch, dinner, meal, or snack (case-insensitive). Each routine keeps its own window; TemPad picks preferred start times with at least 2 hours between meals when possible.

Example: create daily routines named Breakfast, Lunch, and Dinner, then Reschedule — blocks should spread through the day instead of stacking at one preferred time.

If windows are too tight to honor spacing, TemPad keeps your saved preferred times and may show a scheduling note for that day.

Deleting routine occurrences ​

From the calendar, open a routine block and choose Delete to remove this occurrence, this and following, or all occurrences (same as repeating events). Routines are not marked complete per occurrence; excluded occurrences simply stop appearing after the next Reschedule.

For one-off meetings or appointments that should block scheduling, prefer events (from Calendar or task/event editor) or Google Calendar imports.
