Getting started ​

This tutorial walks you through TemPad in about five minutes. Each step matches labels in the live app at jaredescott.github.io/tempad.

Step 1 — Open TemPad and sign in ​

What to click: Open the app, then Sign in with Google or Continue without sign-in.

What you should see: The main shell with sidebar (Calendar, Tasks, Routines, Notepad, Settings).

Common mistake: Expecting cloud sync in local-only mode — that data stays in this browser only.

→ Settings guide · Troubleshooting

Step 2 — Confirm Settings basics ​

What to click: Settings in the sidebar. Review scheduling hours, default list, and scheduler options.

What you should see:

  • At least one scheduling hours profile (e.g. Work hours, Personal hours)
  • A default list for new tasks
  • Optional: Schedule breaks and scheduling horizon under Scheduler

Common mistake: Leaving all days disabled on a profile — the scheduler has nowhere to place tasks.

→ Settings guide

Step 3 — Add tasks ​

What to click: Tasks → add tasks with title, list, due date, and duration.

What you should see: New tasks in the list (and inbox if applicable). Enable priorities in Settings if you want ASAP/High/Normal/Low.

Common mistake: Adding tasks without due dates or duration — auto-schedule needs both to place work.

→ Tasks guide

Step 4 — Connect Google Calendar (optional) ​

What to click: Settings → Google Calendar sync → Connect calendars. Approve access, then enable the calendars you want.

What you should see: Google events appear as busy blocks on the calendar after sync. Requires Google sign-in (not local-only).

Common mistake: Enabling the Calendar API in Google Cloud but not reconnecting in TemPad after a 403 error.

→ Google Calendar guide

Step 5 — Reschedule on the calendar ​

What to click: Calendar → Reschedule (toolbar refresh).

What you should see: Tasks placed into free slots inside your scheduling hours, avoiding events and other blocks.

What to click: The refresh icon in the top toolbar (Recalculate schedule). Blocks may shift as the engine refills open slots.

Common mistake: Expecting instant updates while editing — run Recalculate schedule after bulk changes, or rely on auto-schedule triggers after saves.

→ Calendar guide

Step 6 — Drag and lock (optional) ​

What to click: Drag a task block to a new time on the week view.

What you should see: The block moves and shows a dashed outline (locked). Press Reschedule again to unlock all tasks and recalculate.

Common mistake: Thinking drag permanently overrides dependencies — Reschedule still respects dependency order when recalculating.

→ Calendar guide

Step 7 — Explore task views ​

What to click: Tasks and switch List, Board (Kanban), or Matrix (Eisenhower). Use sidebar list chips to filter. Optional: enable Gantt view (beta) in Settings → Scheduler to add a Gantt tab — a timeline of auto-scheduled task bars (run Reschedule first if it is empty).

What you should see: The same tasks in different layouts; Kanban columns follow your lists; the matrix shows four quadrants (Do first, Schedule, Delegate, Later). With Gantt enabled, scheduled auto-tasks appear as horizontal bars across days.

Eisenhower tips: Enable Use task priorities in Settings for ASAP → Q1. Mark Important / Urgent on tasks, or let due dates imply urgency. Toggle Show inbox tasks in Eisenhower matrix if backlog items should appear.

Common mistake: Forgetting list filters — a hidden list can make tasks seem “missing.”

Animated: switching layouts · Eisenhower drag

→ Tasks guide

Step 8 — Routines, Notepad, list colors (optional) ​

What to click:

  • Routines for recurring protected time
  • Notepad for planning notes; right-click a non-empty line to open a new task with that line as the title (toggle multi-page mode in Settings if needed)
  • Settings → Lists for list colors and cross-theme consistency

What you should see: Routines on their own view; notepad content saved with your app state; colored list indicators across calendar and tasks.

→ Routines · Notepad · Settings
